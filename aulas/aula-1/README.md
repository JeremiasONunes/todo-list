# 📚 Aula 1 - Fundamentos e Setup
**Duração:** 4 horas  
**Foco:** Conceitos fundamentais e configuração inicial

## 🎯 Objetivos da Aula

- Compreender React, Vite e Tailwind CSS
- Aplicar conceitos de Design System e Atomic Design
- Configurar ambiente de desenvolvimento
- Criar primeiros componentes com glass morphism

### Ao final desta aula, você deve ter:

- [ ] Compreendido os conceitos de React, Vite e Tailwind

## 🚀 Preparação

### Antes de começar:
1. Instale Node.js (versão 16+)
2. Instale um editor de código (VS Code recomendado)
3. Abra o terminal/prompt de comando
4. Certifique-se de ter conexão com internet

### Extensões VS Code recomendadas:
- ES7+ React/Redux/React-Native snippets
- Tailwind CSS IntelliSense
- Auto Rename Tag
- Bracket Pair Colorizer
