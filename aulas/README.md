# 🎓 Curso React + Vite + Tailwind CSS
**Desenvolvimento de ToDo List Moderna**

## 📋 Visão Geral do Curso

Este curso ensina desenvolvimento React moderno através da construção de uma aplicação ToDo List completa, abordando conceitos fundamentais e práticas avançadas.

**Duração:** 8 horas (2 aulas de 4h cada)  
**Nível:** Iniciante a Intermediário  
**Projeto:** ToDo List com Glass Morphism Design

## 🎯 Objetivos de Aprendizagem

Ao final do curso, você será capaz de:

- ✅ Criar aplicações React com Vite
- ✅ Implementar design systems com Tailwind CSS
- ✅ Aplicar conceitos de Atomic Design
- ✅ Desenvolver hooks customizados
- ✅ Gerenciar estado e persistência de dados
- ✅ Criar interfaces responsivas e modernas

## 📚 Estrutura do Curso

### **[Aula 1 - Fundamentos e Setup](./aula-1/README.md)** (4 horas)
- Conceitos fundamentais (React, Vite, Tailwind)
- Design System e Atomic Design
- Setup e configuração do projeto
- Primeiros componentes

### **[Aula 2 - Desenvolvimento Completo](./aula-2/README.md)** (4 horas)
- Hook customizado (useTasks)
- Componentes de formulário
- Lista e itens de tarefas
- Integração e funcionalidades avançadas

## 🛠️ Tecnologias Abordadas

- **React 19** - Biblioteca para UI
- **Vite** - Build tool moderna
- **Tailwind CSS 4** - Framework CSS utility-first
- **React Router** - Navegação SPA
- **JavaScript ES6+** - Sintaxe moderna
